Transformed LittleMaid Gun Bridge
=================================

Minecraft 1.20.1 / Forge 47.4.10 向けの非公式クライアント互換MODです。
作者 / 管理者: saltydog16411

目的
----
Transform Into LittleMaid (TILM) でメイド化したプレイヤーと、
HandmadeGuns2 / GVCLib の銃描画を接続します。

主な機能
--------
・メイド化プレイヤーの三人称HMG2/GVCLib銃表示。
・一人称のSteve/Alex腕を選択中のメイドモデル腕へ置換。
・HMG2/GVCLib側の腰だめ、ADS、反動、リロード位置を維持。
・LittleForcesでは選択中のLFS/LFMS基本迷彩腕を使用。

重要
----
このリポジトリは第三者MODのJAR、LittleForcesのモデル/テクスチャ、GVCGun's2の
コンテンツを同梱しません。各前提MODは各作者の正式配布元から入手してください。

正式配布元
----------
GitHub:
https://github.com/saltydog16411/transformed-littlemaid-gun-bridge

Minecraft Japan Forumは日本語での紹介・告知・質問窓口とし、
配布ファイルの正本はGitHub Releasesに一本化します。
